# SmartGen Blog Post Writing Guidelines & Template

This document serves as the official formatting guideline and boilerplate template for publishing articles on the SmartGen Blog. Adhering to this format ensures that all elements—especially metadata and GitHub-hosted images—render correctly on the live production site.

---

## 1. Important Rules for Live Deployment

*   **Image URLs (Crucial):** Never use the standard GitHub `blob` URL. You **must** use the `raw.githubusercontent.com` format for all images to ensure they load on the live site.
    *   *Incorrect:* `https://github.com/bayzed123/SmartGenQR.oi/blob/main/assets/images/image.svg`
    *   *Correct:* `https://raw.githubusercontent.com/bayzed123/SmartGenQR.oi/main/assets/images/image.svg`
*   **File Extension:** Always save the file as `.md`.
*   **Front Matter:** The YAML front matter block (`---`) at the very top of the file is mandatory. Do not skip any keys.
