What Are SEO Meta Tags?

Meta tags are the HTML snippets in a page's <head> that control how it appears in Google search results and when shared on social media — the title link, the description snippet, and the preview card on X, Facebook, or LinkedIn. They don't affect what visitors see on the page itself, only how it's represented everywhere else.

How to Generate Meta Tags

  1. Enter the Site Title — keep it under ~60 characters so Google doesn't truncate it in search results.
  2. Write the Site Description — aim for roughly 150-160 characters; this is what shows as the snippet under your title in search results.
  3. Add Keywords (comma separated) — modern search engines weight this field lightly, but it's still read by some crawlers and internal site-search tools.
  4. Copy the generated tags and paste them into your page's <head>, above the closing </head> tag.

Writing Meta Tags That Actually Help Rankings

The tags themselves are simple; what you put in them is what matters:

1. Every page needs a unique title and description

Duplicate titles/descriptions across pages confuse search engines about which page to rank for a query, and give users no reason to pick one search result over another from the same site.

2. The description is a pitch, not a summary

Google doesn't rank pages higher for a well-written meta description, but a compelling one directly improves click-through rate from the results page — which matters just as much.

3. Open Graph tags control your social preview

Without og:title/og:description/og:image, a link shared on Facebook or LinkedIn can render with a blank or wrong preview — these tags fix that.

Frequently Asked Questions (FAQ)

Q: Do meta keywords still affect Google rankings?

A: No — Google has publicly stated it ignores the meta keywords tag for ranking. It's included here mainly for legacy compatibility and site-internal search tools that may still read it.

Q: What's the ideal length for a meta title and description?

A: Roughly 50-60 characters for the title and 150-160 for the description — beyond that, Google typically truncates them in search results with an ellipsis.

Q: What's the difference between a meta description and an Open Graph description?

A: The meta description appears in Google search results; the Open Graph description (og:description) appears when the link is shared on social platforms like Facebook or LinkedIn. They can be the same text or tailored differently for each audience.
