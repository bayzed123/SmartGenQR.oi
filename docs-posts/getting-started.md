# Getting Started

Welcome to the SmartGen project! This guide will help you get your local environment ready for development.

## Prerequisites

- Node.js (v14 or higher)
- Git

## Installation

```bash
git clone https://github.com/bayzed123/SmartGenQR.oi.git
cd SmartGenQR.oi
npm install
```
