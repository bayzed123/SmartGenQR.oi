# Get Started With SmartGen Barcode System

Start with the browser tool, then connect it to a client product-admin dashboard after the local workflow is confirmed.

## Recommended next action

1. Open the [SmartGen Barcode Service](https://smartgentools.com/barcode-service/) and test a supported format.
2. Read [Installation](installation.md) and [API](api.md) with the client’s technical team.
3. Add the integration to a staging product form, not a production form.
4. Confirm that invalid barcodes block the form and valid barcodes save only through the client’s own backend.
5. Print and scan a representative label before using the workflow in daily operations.

## For ecommerce administrators

Ask the client technical team for the selectors of the existing product form, barcode field, and format field. Do not ask them to share server credentials, API keys, or storage-bucket keys. Those values belong on the client server and are not required by SmartGen’s browser tool.

## For agencies and developers

Use the [API and Product-Form Contract](api.md) as the implementation reference. Keep the first deployment small, document the client’s chosen formats, and let the client backend remain the source of truth for product records.

## Current service position

The documentation presents SmartGen Barcode System as a **$10 lifetime service**. Payments and activation are intentionally deferred while the first-party tool and client-admin workflow are proven stable.
