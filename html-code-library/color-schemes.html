1How To Use

Follow these steps — no coding experience needed.

  1. Browse the palettesEach row moves from a deep shade to a light tint, ready for backgrounds, text and accents.
  2. Click any hex codeClicking the code itself copies it — no separate button needed.
  3. Mix and matchUse the darkest shade for text, the lightest for backgrounds, and a mid-tone for buttons or links.
