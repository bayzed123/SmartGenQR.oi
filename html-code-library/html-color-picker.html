1How To Use

Follow these steps — no coding experience needed.

  1. Pick a colourClick the swatch to open your browser's colour picker, or type a hex code directly.
  2. Read off the format you needHex for most CSS, RGB when you need to add transparency separately, HSL when you want to tweak lightness.
  3. Copy and useEach format has its own copy button — no manual conversion needed.
