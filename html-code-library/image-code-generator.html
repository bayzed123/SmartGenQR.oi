1How To Use

    
Follow these steps — no coding experience needed.

    
  1. Paste your image URLUse any hosted image link — from your own server or an image host.
  2. Add real alt textDescribe the image in a few words; this helps accessibility and image search.
  3. Set size and borderFix a width/height so the page doesn't jump while images load.
  4. Choose alignmentFloat the image left/right to wrap text around it, or centre it on its own.
