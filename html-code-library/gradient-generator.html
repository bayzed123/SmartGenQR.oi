1How To Use

    
Follow these steps — no coding experience needed.

    
  1. Pick two coloursChoose a start and end colour using the swatches or by typing a hex code.
  2. Choose linear or radialLinear blends in a straight line; radial blends outward from the centre.
  3. Set the angleFor linear gradients, drag the slider to rotate the direction of the blend.
  4. Copy the CSSPaste the single background line into any element's style or stylesheet.
