# SmartGen Text Converter Suite

This folder is an isolated addition to the SmartGen repository. It contains a single-page browser-local toolkit with five converters: Plain Text to HTML, Markdown to HTML, HTML to Markdown, HTML to Plain Text, and Plain Text to Markdown.

The existing SmartGen site, HTML Code Library, tools, docs, and other repository files are intentionally not modified by this addition. Open `index.html` to use the suite directly, or serve the repository through GitHub Pages at `/SmartGenQR.oi/text-converter-suite/`.

All transformations happen in the browser. Source text is not uploaded or sent to a conversion API. The page includes a title, meta description, canonical URL, Open Graph metadata, favicon, and Organization JSON-LD schema for SmartGen Labs.
