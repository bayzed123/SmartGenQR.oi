SmartGen Developer Documentation

Welcome to the SmartGen developer documentation. This guide provides comprehensive information about the project structure, coding standards, and contribution guidelines.

Getting Started

SmartGen is a collection of free, client-side web utilities built with vanilla JavaScript, HTML, and CSS. To get started with development:

Prerequisites

  • Node.js 14+ and npm
  • Git for version control
  • A code editor (VS Code recommended)
  • Basic knowledge of HTML, CSS, and JavaScript

Installation

git clone https://github.com/bayzed123/SmartGenQR.oi.git
cd SmartGenQR.oi
npm install

Development Server

To run the project locally, you can use any local server. For example:

npx http-server .

Then open http://localhost:8080 in your browser.

Project Structure

The SmartGen project follows a modular structure where each tool is organized in its own directory:

SmartGenQR.oi/
├── assets/
│   ├── css/
│   │   ├── style.css          # Global styles
│   │   └── blog.css           # Blog-specific styles
│   └── js/
│       ├── app.js             # Main application logic
│       ├── blog.js            # Blog functionality
│       └── search.js          # Search functionality
├── blog-posts/                # Markdown files for blog posts
├── blog/                      # Generated blog HTML pages
├── scripts/
│   ├── build-blog.js          # Blog builder script
│   └── seo-optimizer.py       # SEO optimization utilities
├── [tool-name]/
│   └── index.html             # Individual tool pages
├── index.html                 # Homepage
├── sitemap.xml                # XML sitemap for SEO
└── package.json               # Project dependencies
Note: Each tool directory contains a self-contained index.html file with all necessary CSS and JavaScript embedded or linked.

Coding Standards

To maintain code quality and consistency across the project, please follow these guidelines:

JavaScript

  • Use 2-space indentation
  • Use const by default, let for variables that change
  • Use camelCase for variable and function names
  • Add JSDoc comments for functions and complex logic
  • Use template literals for string interpolation

HTML

  • Use semantic HTML elements (e.g., <section>, <article>)
  • Always include proper meta tags for SEO
  • Use descriptive class names following BEM methodology
  • Ensure accessibility with ARIA attributes where needed

CSS

  • Use CSS custom properties (variables) for colors and spacing
  • Follow a mobile-first responsive design approach
  • Use flexbox and CSS Grid for layouts
  • Minimize the use of !important
  • Group related properties together

Blog System

SmartGen includes an automated blog system that converts Markdown files into static HTML pages with full SEO support.

Creating a Blog Post

To create a new blog post, add a Markdown file to the blog-posts/ directory with the following front matter:

---
title: "Your Blog Post Title"
description: "A brief description for SEO"
date: "2026-06-16"
tags: ["tag1", "tag2", "tag3"]
category: "Category Name"
image: "https://example.com/image.jpg"
author: "Author Name"
---

# Your Content Here

This is your blog post content in Markdown format.

Building Blog Posts

After adding or modifying blog posts, run the build script:

npm run build

This script will:

  • Convert Markdown files to HTML pages
  • Generate blog.json with metadata
  • Automatically update sitemap.xml with blog URLs
  • Preserve original post dates for SEO
Pro Tip: The sitemap automatically uses each post's original publication date for the lastmod attribute, ensuring search engines recognize the content's age correctly.

Sitemap Management

The sitemap.xml is automatically updated when you run npm run build. Each blog post includes:

  • <loc> - The full URL of the post
  • <lastmod> - The post's original publication date
  • <changefreq> - Update frequency (weekly for posts)
  • <priority> - Relative priority (0.7 for posts, 0.9 for main blog)

Contributing

We welcome contributions! Here's how to get started:

Steps to Contribute

  1. Fork the repository
  2. Create a feature branch: git checkout -b feature/your-feature
  3. Make your changes and commit: git commit -m "Add: description"
  4. Push to your fork: git push origin feature/your-feature
  5. Open a Pull Request with a clear description

Commit Message Format

Use the following format for commit messages:

Type: Description

- Detailed explanation
- Additional context if needed

Example:
Fix: Correct sitemap generation for blog posts

Ensures that all blog posts are correctly included in the sitemap.xml
by modifying the build script to use original post dates.
Important: Always test your changes locally before submitting a PR. Ensure all scripts run without errors.

Deployment

SmartGen is deployed as a static site, making it easy to host on any platform:

Deployment Options

  • GitHub Pages: Push to gh-pages branch
  • Netlify: Connect your GitHub repository
  • Vercel: Deploy with zero configuration
  • Traditional Hosting: Upload files via FTP/SFTP

Pre-Deployment Checklist

  • Run npm run build to generate latest blog pages and sitemap
  • Test all tools in different browsers
  • Verify sitemap.xml is valid at XML Sitemap Validator
  • Check for broken links using a link checker tool
  • Verify mobile responsiveness
