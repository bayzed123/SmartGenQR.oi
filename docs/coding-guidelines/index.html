Coding Guidelines

To maintain a high-quality codebase, we follow these guidelines.

JavaScript

  • Use ES6+ features.
  • Follow the camelCase naming convention.

CSS

  • Use CSS variables for theme-related colors.
  • Follow a mobile-first approach.
